Gmail / Hotmail · อ่านเฉพาะเมื่อกดตรวจสอบ

1. ตั้งค่าอีเมลที่ใช้รีไอดี

กรอกอีเมลหลัก
ต้องสร้าง Shortcut ชื่อ “เปิดเกม Kuroko” ไว้แล้ว · ข้อมูลอีเมลหลักและหมายเลขรอบเก็บเฉพาะในเบราว์เซอร์

2. ตั้งค่า OAuth Client ID

Client ID เป็นตัวระบุแอปแบบสาธารณะ ไม่ใช่รหัสผ่านหรือ client secret · กรอกเฉพาะผู้ให้บริการที่ต้องการใช้ · ต้องลงทะเบียน URL ของเว็บนี้กับผู้ให้บริการ

3. เชื่อมกล่องอีเมล

ยังไม่ได้เชื่อมกล่องจดหมาย

กดตรวจสอบเมื่อคาดว่า OTP ส่งมาถึงแล้ว (ไม่มีการอ่านอีเมลเบื้องหลัง) โปรแกรมแสดงเฉพาะ 10 ข้อความล่าสุดใน 24 ชั่วโมง และค้นหารหัส 4–8 หลักจากข้อความสั้น อาจพบตัวเลขที่ไม่ใช่ OTP ได้ จึงต้องตรวจสอบผู้ส่งด้วยตัวเอง

4. บันทึกผลสุ่ม

ไม่บันทึกเนื้อหาอีเมล OTP รหัส OTP หรือ access token ลงในประวัติ
